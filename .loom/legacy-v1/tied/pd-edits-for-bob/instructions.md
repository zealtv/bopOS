# pd-edits-for-bob

**The waiting room for `.pd` work.** Bob is the only one who edits Pure Data;
this stitch stays `.waiting` on him and is the visible collection point
(Bob's request, 2026-07-10) so pending PD edits never hide inside tied
stitches again.

The live list is **`.notes/pd-edits-for-bob.md`** — OS-layer edits to
`pd/bopos.osc.pd` (restart-engine, identify chirp, retire old emitters,
`route p`, and the seam council's `/os/master` + point-scalar delivery) plus
the reference-patch / starter-kit wave (`bopos.out~`, `bopos.point`, `/cue`
receiver, level meter). Agents: append new edits to that file as stitches hit
them, and note them here only if the shape of the work changes.

Since patches are being rewritten for this bopOS version (no backwards
compat), treat the list as one rewrite wave, not incremental edits. The
SuperCollider starter-kit twin is agent-buildable and is NOT gated here —
only `.pd` files are.

Tie when the wave lands on the reference patch and the list is empty (or
everything left is deliberately deferred).
