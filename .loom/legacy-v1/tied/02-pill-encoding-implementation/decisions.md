# Superseded hash-palette guard ruling

The ratified design explicitly removes `PILL_PALETTE_SIZE` and
`.show-pill-0..7`. Historical tied theme guards that assert those selectors or
their literal colour trios describe the superseded alias-hash implementation.

Per the 2026-07-23 durable-test ruling in `CLAUDE.md`, the tied archive remains
an authoring record and is not repaired into a pseudo-regression suite. The
focused verifier in this stitch replaces those assertions with durable
surface behavior:

- every message mode/generator maps to its semantic class and visible code;
- both theme token sets resolve to eight distinct fills;
- focus, drop, and drag state preserve category paint;
- no legacy numeric hash class reaches the DOM.

The broader theme tokens and semantic `--green` invariant are unchanged.
