# device-alias-implementation

Implement the ratified physical-device alias design retained at
`.lore/items/2026-07-16-device-alias-design-ratified/content/proposal.md`.

Deliver a durable global host registry, deterministic curated alias generator,
genuine Forget semantics, editing/reset controls, and one shared identity
hierarchy across Devices, Seats, Assets and Dashboard. Aliases must never leak
into Seat names, hostname, node state, OSC, venue snapshots, or virtual devices.

Complete children in their encoded order and tie this goal only after focused
backend and real-dashboard browser verification passes.
