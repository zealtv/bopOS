# 01-layout-review

Run a brief Show-layout design session with Bob before implementing the two
layout children. Start from `ui-review.md` and the current wide/narrow Show tab.

Ratify only the interaction details that affect implementation:

- edit-bar grouping, labels/icons, insertion point, and selection target for
  Duplicate/Delete when a message is focused;
- whether duplicating a divider is useful and whether deleting a non-empty step
  needs confirmation;
- the terminal fixed height and responsive breakpoint; and
- click-to-edit step-name keyboard/touch behavior.

Produce a compact desktop and narrow wireframe or annotated screenshot. Record
the decisions in this stitch, update the implementation children if necessary,
and get Bob's review before tying. Do not change the show schema or implement
lanes/scenes here.
