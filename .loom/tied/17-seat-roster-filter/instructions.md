# 17-seat-roster-filter

Keep the Seats workspace roster usable for large installations:

- Bound the roster to a sensible visible row count and scroll within it.
- Add the same name-prefix Filter Seats pattern used by the Group membership
  inspector, including a clear no-match state.
- Preserve Seat numeric order, selection, inline naming, heartbeat, and patch
  status behavior.
- Verify desktop and touch-width containment, live filtering while typing, and
  recovery after clearing the filter.
- Apply the same bounded-scroll containment to the Physical devices roster;
  retain its existing categorical dropdown and do not add name search there.
