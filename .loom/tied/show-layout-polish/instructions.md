# show-layout-polish

Make the current one-lane Show workspace denser and more operational without
changing the show document or playback model.

This thread follows Bob's 2026-07-20 layout brief and the UI review retained in
`01-layout-review/ui-review.md`. Ableton Live is the reference for a persistent,
compact editing strip; QLab is the reference for terse cue-list actions and
legible operational consoles.

Work in order:

1. `01-layout-review` — brief review/design session and ratified interaction
   details;
2. `02-edit-bar-and-inline-step-name` — compact edit bar, remove Arrange, and
   click-to-edit step name; then
3. `03-responsive-osc-terminals` — fixed-height side-by-side consoles with
   narrow stacking.

Future lanes/scenes are deliberately excluded. Their schema and independent
follow-action semantics live in
`scene-sequencing/show-lanes-and-scenes-design.waiting`.
