# fleet-testing

Close the remaining fleet-scale and real-installation acceptance work as one
umbrella campaign.

The children keep their distinct contracts:

- `asset-fleet-distribution` — design and prove safe, observable asset rollout
  across multiple physical nodes;
- `clock-sync` — measure real installation-WiFi cue spread against the stated
  jitter target;
- `spatial-audio` — run the audible multi-node point/cue acceptance sweep.

Software-only history remains tied in the original stitch records. This
umbrella closes only when the asset rollout path is accepted and the clock and
spatial behavior have evidence from a representative physical fleet. Record
the rig, network, node count, patch/engine, commands, measurements, audible
observations, and limitations in each child.
