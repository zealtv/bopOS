# 06-remaining-durable-surface-triage

Resolve durable surfaces not covered by children `02`–`05`.

- Use `01`'s matrix and findings from the migration stitches; do not perform a
  blind all-guard sweep.
- For each candidate, ask whether the property should be guaranteed across
  future implementation, layout, and wording changes.
- Add focused living tests for genuine shared contracts, grouped by owning
  code surface.
- Send one-time UI geometry, copy, CSS mechanism, screenshots, and delivery
  proofs to the retirement ledger instead of preserving them as regressions.
- Split again if a newly discovered surface is too large for one stitch.

Document promoted and rejected candidates for `08`.
