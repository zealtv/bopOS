# Land work before the usage window closes

When a session is long or near its usage limit, work in small slices that each verify and commit, so nothing is left mid-flight.

Bob (2026-07-14): *"try and land before the 5hr usage window. you can use the whole window, just try not to leave the project midflight if the usage limit hits."* Before starting anything sizeable, ask whether it can be finished and committed in the time left; if not, split it or park it cleanly in its stitch. Prefer inline work over large subagent runs late in a window — a monolithic run can't be landed partially.

- usage window
