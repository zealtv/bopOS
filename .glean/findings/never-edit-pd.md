# Never edit Pure Data patches

When a change would touch a `.pd` file, stop: Pd patching is Bob's domain, so write the needed edit down for him instead.

Agents work on Python, Bash, JS/HTML, architecture and docs. Record the exact Pd change needed — receiver spellings, message shapes, expected behaviour — as a checklist item on the loom thread `64-pd-edits-owed`, verify the Python/dashboard/simfleet side on its own, and leave the audible check to Bob.

## Triggers

- .pd
- 64-pd-edits-owed
- bopos~.pd
