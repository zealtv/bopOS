# Agent orientation

Read and follow [`CLAUDE.md`](CLAUDE.md); it is the shared agent guide and the
single source of current instructions for this repository. Do not duplicate its
rules here.

- Read the newest `.notes/handoff-*.md` for the latest launch state.
- Run `./.loom/loom.sh status` for live work and follow the loom claim → work → tie
  protocol. Work one stitch at a time unless Bob explicitly requests otherwise.
- Use [`docs/VERIFICATION.md`](docs/VERIFICATION.md) to choose the appropriate
  verification level.
- Never edit `.pd` files; record required Pure Data work in
  `.notes/pd-edits-for-bob.md`.
