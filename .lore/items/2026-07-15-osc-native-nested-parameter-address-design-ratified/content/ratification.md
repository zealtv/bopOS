# Ratification

Bob ratified both the nested parameter-address and Seat-group selector proposals
on 2026-07-15.

For parameter addresses this locks:

- optional manifest `path` array plus leaf `name`;
- slash-joined canonical dashboard and preset keys;
- true nested `/p/...` OSC addresses through every engine boundary;
- remove-plus-add semantics when a qualified identity changes;
- `path` as authoritative hierarchy, with legacy `group` remaining
  presentation-only compatibility;
- clean composition with lowercase `g<id>` fleet selectors.
